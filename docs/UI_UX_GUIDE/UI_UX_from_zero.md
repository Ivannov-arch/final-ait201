## Segmen 5: The 28 Day Roadmap

Week one is all about training your eye. Start by building yourself a swipe file, 20 or so hero sections and feature sections that really inspire you, pulled from Mobin, Dribble, Pinterest, or wherever. This is where you pick one design you genuinely love from the swipe file and clone the hero section exactly.
